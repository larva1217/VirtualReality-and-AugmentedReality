# 🎮 VR/AR/게임제작기초

## 📚 교과목 개요

Unity를 활용하여 게임 제작의 기초와 VR/AR 콘텐츠 개발을 학습한 과목입니다.

Unity의 구성 요소와 기본 기능, 게임 개발 프로세스 및 기초 이론을 학습하고, C# 프로그래밍을 통해 다양한 기능을 구현했습니다.

VR 콘텐츠는 Unity의 **XR Plugin Management**를 사용하여 개발하였으며, **Meta Quest 2** 기기를 활용해 오브젝트 그랩, 상호작용, 이동 등 VR 기능을 구현했습니다.

AR 콘텐츠는 Unity에서 개발한 애플리케이션을 **Android 스마트폰**에 빌드하여 실행하고, 카메라를 이용한 마커 인식 및 3D 오브젝트 출력 등 AR 기능을 구현했습니다.

매주 Chapter별 실습 및 프로그래밍 과제를 수행하고, 학기말에는 산학연계 기말 프로젝트를 제작했습니다.

본 교과목은 산학연계 교과목으로, (주)오르카소프트가 제시한 프로젝트를 구현하기 위해 이론 및 실습을 진행했으며, 완성된 프로젝트는 기업으로부터 평가를 받았습니다.

## 💻 사용 기술

- Unity
- C#
- XR Plugin Management
- Meta Quest 2
- Android


## 📌 참고

본 저장소는 **VR/AR/게임제작기초** 수업에서 수행한 실습, 과제, 프로젝트를 정리한 포트폴리오입니다.
