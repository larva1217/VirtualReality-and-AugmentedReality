# 🎮 Unity VR/AR 콘텐츠 제작 프로젝트

## 📖 프로젝트 소개

이 프로젝트는 상용 게임 엔진인 Unity3D를 활용하여  
3차원 가상현실(VR) 및 증강현실(AR) 콘텐츠를 제작하는 것을 목표로 진행되었습니다.

가상현실 HMD 장비를 활용한 VR 콘텐츠와  
모바일 기기를 활용한 AR 콘텐츠를 직접 구현하며,  
가상현실과 증강현실의 원리를 이해하고 실제로 적용하는 과정을 학습하였습니다.

기말 프로젝트에서는 Unity를 기반으로 한  
VR/AR 콘텐츠를 직접 기획하고 구현하였습니다.

---

## 🎯 교과 목표

### ✅ 목표
Unity3D를 이용한 VR/AR 콘텐츠를 제작할 수 있다.

### 🧠 지식
가상현실(VR)과 증강현실(AR)의 원리를 이해하고 습득한다.

### 💻 기술
가상/증강현실 애플리케이션 구현을 위한  
Unity 프로그래밍 능력을 향상시킨다.

---

## 🛠 사용 기술

- Unity3D
- C#
- VR (Virtual Reality)
- AR (Augmented Reality)
- Vuforia
- AR Foundation
- XR Interaction Toolkit
